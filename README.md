# 💰 Финансовый анализатор

Приложение для учёта личных финансов под Android. HTML/CSS/JS в Capacitor WebView; собственный сервер не нужен. Облачный ИИ вызывается только по запросу пользователя: финансовая сводка и вопрос отправляются выбранному API.

## Возможности

- **Учёт доходов и расходов** — категории с иконками, цветами и месячными бюджетами
- **Черновики из уведомлений** — приложение сохраняет только подходящие по источнику и содержанию уведомления и предлагает подтвердить операцию. Точность зависит от формата банка; каждую сумму и тип следует проверить перед записью.
- **ИИ-советник** — работает и офлайн (анализ нормы сбережений, темпа трат, бюджетов, подписок, мелких покупок), а при вставке токена любого OpenAI-совместимого API (OpenAI / OpenRouter / Groq) даёт полноценный разбор финансов
- **Аналитика** — графики доходов/расходов за полгода, структура трат по категориям, топ мест трат
- **Автообновление** — приложение само проверяет GitHub Releases и предлагает скачать новую версию
- **Бэкап/восстановление** в JSON, демо-режим для показа

## Сборка APK (один раз)

1. Настройте секрет `KEYSTORE_BASE64` в GitHub Actions (постоянный ключ подписи).
2. Запустите `.github/workflows/build.yml` в **Actions** или отправьте коммит в `main`.
3. После зелёной сборки скачайте `app-release.apk` из **Releases**. Перед передачей клиенту проверьте SHA-256, подпись, установку и сценарий обновления на реальном телефоне.

Каждый push в `main` проверяет парсер и собирает подписанный release APK с тегом `vX.Y.Z-bN`. Для новой версии измените `version` в `package.json` и `APP_VERSION` в `www/js/config.js`.

### Постоянный ключ подписи (обязательно, один раз)

Без прежнего ключа Android не установит обновление поверх старой версии. Настройка:

1. Откройте репозиторий → **Settings → Secrets and variables → Actions → New repository secret**
2. Имя: `KEYSTORE_BASE64`, значение: всё содержимое файла `KEYSTORE_BASE64.txt` (выдаётся разработчиком вместе с проектом) → **Add secret**
3. Не публикуйте ключ и не передавайте его клиенту. Сохраните копию ключа отдельно от репозитория: потеря ключа лишит возможности обновлять установленное приложение.
4. Если прежняя установка была подписана другим ключом, сначала сохраните JSON-бэкап, удалите приложение, установите новую сборку и восстановите данные.

## Перед передачей клиенту

- Запустите `npm test`, затем соберите release APK в Actions и установите именно файл из успешного релиза.
- Проверьте на телефоне клиента три реальные покупки, два одинаковых платежа и одно зачисление. Исправьте черновики вручную, если банк сообщает их неоднозначно.
- Проверьте бэкап и восстановление. Токен облачного ИИ в бэкап не входит и после перезапуска вводится снова.
- Доступ к уведомлениям открывает приложению системный поток уведомлений; служба отбирает сообщения известных банков и банковские SMS с признаками операций. Черновики и история хранятся на устройстве. Удалить пойманные тексты можно на экране уведомлений.
- Показатель «Учтённый итог» равен доходам минус расходам, записанным в приложение. Он не обязан совпадать с фактическим остатком в банке, если история неполная.

## Настройка на телефоне

1. Установить APK (разрешить установку из неизвестных источников)
2. **Android 13+: разблокировать ограниченные настройки.** Приложение установлено не из маркета, поэтому Android блокирует ему доступ к уведомлениям («Настройки с ограниченным доступом»). Снимается так: **Настройки телефона → Приложения → Финансовый анализатор → ⋮ (три точки сверху) → Разрешить ограниченные настройки** → подтвердить. Делается один раз.
3. Для автоимпорта трат: **Ещё → Операции из уведомлений → Открыть настройки доступа** → включить доступ к уведомлениям для FinAnalyzer
4. (Опционально) **Ещё → ИИ-токен** → вставить ключ OpenAI-совместимого API

> При обновлении на новую версию: установить свежий APK поверх старого (данные сохранятся). Приложение само предложит обновление, когда выйдет новый релиз.

## Структура

```
www/            веб-приложение (ванильный JS, без сборки)
  js/config.js  версия, репозиторий обновлений, категории, ключевые слова
  js/store.js   хранилище и статистика
  js/parser.js  парсер текстов уведомлений банков
  js/ai.js      офлайн-советы + облачный ИИ
  js/updater.js автообновление через GitHub Releases
  js/notify.js  мост к нативному слушателю уведомлений
native/         Java-модуль NotificationListenerService (подкладывается в android/ при сборке)
build-apk.yml.txt  workflow для Actions (переименовать в .github/workflows/build.yml)
```
