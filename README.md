# 💰 Финансовый анализатор

Продвинутое приложение для учёта личных финансов под Android. Ванильный стек (HTML/CSS/JS в Capacitor WebView) — никаких серверов, все данные только на устройстве.

## Возможности

- **Учёт доходов и расходов** — категории с иконками, цветами и месячными бюджетами
- **Автоматический импорт из уведомлений** — приложение читает уведомления банков (Сбер, Т-Банк, Альфа, ВТБ и др.) и само предлагает записать операцию: сумма, магазин, категория определяются автоматически
- **ИИ-советник** — работает и офлайн (анализ нормы сбережений, темпа трат, бюджетов, подписок, мелких покупок), а при вставке токена любого OpenAI-совместимого API (OpenAI / OpenRouter / Groq) даёт полноценный разбор финансов
- **Аналитика** — графики доходов/расходов за полгода, структура трат по категориям, топ мест трат
- **Автообновление** — приложение само проверяет GitHub Releases и предлагает скачать новую версию
- **Бэкап/восстановление** в JSON, демо-режим для показа

## Сборка APK (один раз)

1. Откройте репозиторий на GitHub → **Add file → Create new file**
2. Имя файла: `.github/workflows/build.yml`
3. Вставьте всё содержимое файла `build-apk.yml.txt` (без первых строк-комментариев можно оставить — это YAML-комментарии) → **Commit changes**
4. **Actions** → дождаться зелёного запуска → **Artifacts → app-debug-apk**

Каждый push в `main` собирает новый APK и публикует релиз `vX.Y.Z-bN` — установленные приложения сами увидят обновление. Чтобы выпустить обновление, поднимите `version` в `package.json` и в `APP_VERSION` в `www/js/config.js`.

## Настройка на телефоне

1. Установить APK (разрешить установку из неизвестных источников)
2. **Android 13+: разблокировать ограниченные настройки.** Приложение установлено не из маркета, поэтому Android блокирует ему доступ к уведомлениям («Настройки с ограниченным доступом»). Снимается так: **Настройки телефона → Приложения → Финансовый анализатор → ⋮ (три точки сверху) → Разрешить ограниченные настройки** → подтвердить. Делается один раз.
3. Для автоимпорта трат: **Ещё → Операции из уведомлений → Открыть настройки доступа** → включить доступ к уведомлениям для FinAnalyzer
4. (Опционально) **Ещё → ИИ-токен** → вставить ключ OpenAI-совместимого API

> При обновлении на новую версию: установить свежий APK поверх старого (данные сохранятся). Приложение само предложит обновление, когда выйдет новый релиз.

## Структура

```
www/            веб-приложение (ванильный JS, без сборки)
  js/config.js  версия, репозиторий обновлений, категории, ключевые слова
  js/store.js   хранилище и статистика
  js/parser.js  парсер текстов уведомлений банков
  js/ai.js      офлайн-советы + облачный ИИ
  js/updater.js автообновление через GitHub Releases
  js/notify.js  мост к нативному слушателю уведомлений
native/         Java-модуль NotificationListenerService (подкладывается в android/ при сборке)
build-apk.yml.txt  workflow для Actions (переименовать в .github/workflows/build.yml)
```
