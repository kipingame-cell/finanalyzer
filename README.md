# Финансист

![Обложка проекта](docs/assets/poster.webp)

**Операции, категории и месячная аналитика**

Локальный финансовый анализатор: банковские уведомления, импорт выписок, категории, бюджеты и аналитика по месяцам.

**Тип:** Android · личные финансы · **Версия:** 1.6.1 · **Документация сверена:** 2026-10-08.

[Версии и скачивание](docs/RELEASES.md) · [Аудит и предложения](docs/AUDIT.md) · [Исходники](https://github.com/kipingame-cell/finanalyzer) · [Сборки](https://github.com/kipingame-cell/finanalyzer/actions)

## Возможности

- Импорт операций из банковских уведомлений и PDF/текста выписок.
- При совпадении операции подтверждённая выписка имеет приоритет перед уведомлением.
- Переводы между своими счетами выделены из обычных доходов и расходов.
- Навигация по месяцам, категории, бюджеты, графики, резервное копирование.
- ИИ-функции и проверка обновлений используют сеть; локальная аналитика работает на данных устройства.

## Запуск и проверка

```bash
npm install
npm test
npm run build
npx cap add android
npx cap sync android
```

[APK 1.6.1](https://github.com/kipingame-cell/finanalyzer/releases/download/v1.6.1-b59/app-debug.apk). Для новой версии проверяйте тег и имя APK в Releases. PDF-модуль подготавливается скриптом `pretest` при `npm test`; установка зависимостей обязательна.

## Проверенное состояние

Локально 80 проверок прошли; одна проверка извлечения PDF не запустилась без подготовленного pdfjs-dist. Установка точной зависимости в этом окружении недоступна. Последняя APK-сборка GitHub Actions исходного коммита успешна; workflow не запускает npm test автоматически.
